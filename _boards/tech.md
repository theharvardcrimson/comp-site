The Crimson's Tech Board is the only organization on campus where you'll get to
work on a tech-related project with real users, real consequences, and real-world
experience.

And this year will be more exciting than ever. You'll learn how to work in teams
as engineers, and, ultimately, contribute to the largest redesign of The Crimson
site and backend to date using industry-relevant technologies such as Svelte, Go,
and TailwindCSS (alongside our current React + Django + GraphQL production stack).

You'll be working with a production codebase and see the impact: The Crimson gets
21 million views a year, and we are the go-to source for Harvard-related news.

For those interested in frontend development, you'll build both reader-facing
features and internal tools that editors use every day. Upcoming projects include
redesigning the admin UI, new features like improved article scrolling, and
contributing to the ongoing site redesign. We also have a range of other projects
like data visualizations, interactives, and scrolls (interactive, long-form
articles).

For people interested in backend development, The Crimson has an extensive stack
built with Docker, Django (Python), GraphQL, PostgreSQL, Redis/Celery, and AWS. We
currently operate using our own proprietary content management system — one of the
few newspapers (even including professional ones) to do it. Some projects we are
looking forward to include speeding up site regeneration, improving deploy
workflows, and purging Cloudflare cache when regenerated pages need to go live
immediately.

In addition to all that, there will be opportunities to integrate AI into newsroom
workflows and develop AI tools that support the news reporting efforts of other
boards. We're flexible about matching you to work you're excited about, as long as
you're interested in building real tech.

The Tech Comp is designed to accommodate programmers with all levels of experience.
However, it will be highly beneficial for the company to be experienced with some
programming language — it doesn't have to be web development.
