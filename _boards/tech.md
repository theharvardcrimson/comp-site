Tech is one of the only places on campus where you'll ship code to a
production site with real users and real consequences. The Crimson serves
millions of page views a year on a stack we built and run ourselves — one of
the few newsrooms, professional ones included, with a proprietary CMS.

Tech board members build reader-facing features and the internal tools our
editors use every day. On the frontend, this includes projects like data
visualizations, interactives, and scrolls — interactive, long-form articles.
On the backend, it includes speeding up site regeneration, improving deploy
workflows, and purging Cloudflare cache.

Unlike most Crimson boards, Tech comp is competitive. Over the course of
several weeks, compers will submit a deliverable and discuss their code in a
final round interview. It is recommended that you have experience with some
programming language, but it doesn't have to be web development, and our
comp is designed to accommodate programmers with all levels of experience.
