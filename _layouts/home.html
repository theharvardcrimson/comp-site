{%- comment -%} Click-to-load, and it plays in place.
is the same native disclosure the nav drawer uses, so this still ships no JavaScript. Why not a plain iframe, which is what the old site had: it costs about 1MB of Google's player on every page view whether or not anyone watches, and it reaches a third party before the visitor has asked for anything. Inside a closed
the iframe is display:none, so loading="lazy" never fires -- nothing is requested until someone opens it. Verified by watching the network: zero youtube requests on load. autoplay=1 is what makes it play rather than needing a second click. Opening the disclosure is a user gesture, which is what browser autoplay policies require, so the click that opens it is the click that starts it. If a browser refuses, the player is still there and its own play button works -- degrades to two clicks, never to nothing. The label is the video's title, not "Watch this", because it is also the disclosure's accessible name and has to make sense in both states. {%- endcomment -%}
