{% comment %} Continuously rotating marquee of the ten board names, each linking to its board page. Three accessibility consequences of it moving AND being interactive, all handled here: 1. It auto-plays, so WCAG 2.2.2 requires a way to stop it. The checkbox is a real, keyboard-operable pause control with no JavaScript. Screen readers announce it as a checkbox with its state. 2. A moving link is hard to click and hard to keep focus on, so the track also pauses on hover and on focus-within (see main.css). Reach for a link and it stops. 3. The list prints twice so translateX(-50%) wraps with no visible gap, but only the FIRST pass is links. The second is inert spans, aria-hidden, so the ten boards appear once in the tab order and once to a screen reader rather than twice. Names come from `name`, not `display_name`: no "(Flyby)" or "(FM)" here. Those stay on each board's own page. {% endcomment %} {% assign tick = site.boards | sort: 'name' %}
