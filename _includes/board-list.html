{% comment %} The ten boards, in the owner's chosen running order (not alphabetical -- that was tried first and replaced at the owner's request). Each row is one link -- the whole band is the target, so no chevrons or "read more" needed. Sorted by `order`, set on all ten files. This field is deliberately required on every one of them: Jekyll's sort filter silently yields an empty list if even one document is missing the sort property, which is exactly what happened when this was tried once before with only some files set -- the whole board list vanished from the page. If the order ever changes, renumber all ten, not just the ones that moved. The hover colour-flip is decoration: every row states its board and description in text, so nothing depends on hover. instead of a plain link -- clicking it fills the screen with that board's full content rather than navigating away. name="board-popup" is shared across every row so browsers keep at most one open at a time, the same way radio inputs with a shared name do.
