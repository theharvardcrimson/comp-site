{% comment %} The ten boards, alphabetical. Each row is one link -- the whole band is the target, so no chevrons or "read more" needed. Sorted by 'name', NOT by an 'order' field. Jekyll's sort filter silently yields an empty list when the property is missing from every document, which is exactly what happened: the whole board list vanished from the page while the footer list (sorted by name) rendered fine. If a deliberate running order is ever wanted, add `order:` to all ten files -- all ten, or this breaks again. The hover colour-flip is decoration: every row states its board and description in text, so nothing depends on hover. PROTOTYPE: a board with `popup: true` in its front matter (News, for now) renders as a native
instead of a plain link -- clicking it fills the screen with that board's full content rather than navigating away. name="board-popup" is shared across every popup-enabled row so browsers keep at most one open at a time, the same way radio inputs with a shared name do. The rest still link to their standalone page until this is approved and rolled out to all ten. {% endcomment %}
